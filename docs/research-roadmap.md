# 研究路线

## 研究问题

围绕“小目标在检测器中特征不足与尺度不匹配”建立问题，不先假设某个模块一定有效。

可验证的问题示例：

1. 增加高分辨率特征分支能否提高小目标召回率，代价是多少？
2. 切片推理对小目标有效，但如何处理边界割裂和重复框？
3. 动态标签分配能否改善小目标的训练样本质量？
4. 针对尺度分布重采样，是否比直接增加模型容量更划算？

## 基线协议

所有对比实验必须固定：

- 数据集版本与划分；
- 输入分辨率；
- 模型初始化；
- 训练轮数、批大小、优化器；
- 评价指标与置信度阈值；
- 随机种子；
- 推理后处理。

## 推荐指标

- Precision、Recall；
- mAP50、mAP50-95；
- AP_small、AP_medium、AP_large；
- 参数量、FLOPs、推理时延、显存；
- 分场景或分目标尺寸的召回率。

## 第一阶段方法候选

优先选择一个容易隔离变量的方向：

1. P2 高分辨率检测头；
2. 多尺度特征融合改进；
3. SAHI 风格切片训练或推理；
4. 小目标感知的数据增强；
5. 针对尺度不平衡的损失函数或标签分配。

不要一次堆叠多个改进。先证明每个模块单独有效，再证明组合收益。

## 论文前必须确认

- 导师是否认可研究问题和创新点；
- 数据是否允许用于研究和公开发布；
- 比较方法是否能公平复现；
- 是否有多数据集或多种子证据；
- 失败样例、计算成本和限制是否被诚实报告。
